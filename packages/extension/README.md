# TickerDock

TickerDock is a VS Code market watch extension powered by `stock-api` and
`fund-api`. It supports stock, fund, futures, Binance, forex, flash-news, Xueqiu,
portfolio, reminder, local trend-chart, and AI research workflows.

Credentials such as Xueqiu Cookies and AI API keys are stored in VS Code
SecretStorage. Webviews use allowlisted host-side data and restrictive content
security policies.

See the workspace README and migration document for configuration and migration
details.

Marketplace builds use the `tickerdock.tickerdock` extension identifier.

技术保障

为开发者打造，安全透明可审计

分层架构、受限 Webview 与加密凭证存储，每行代码都可以在 GitHub 上审查。

SecretStorage 加密

API Key 等敏感凭证进入 VS Code 安全存储，不出现在配置文件、日志或 Webview 状态中。

CSP 沙箱隔离

Webview 使用受限内容安全策略，数据代理限制访问范围，缩小不可信内容的运行边界。
